🚀 COMECE EM 3 PASSOS:

PASSO 1 - Setup do Banco de Dados (2 min)
──────────────────────────────────────
1. Abra: http://localhost/phpmyadmin
2. Selecione banco "trabalho"
3. Abra aba "SQL"
4. Copie conteúdo de: setup.sql
5. Cole em phpMyAdmin e execute

✅ Pronto! Tabelas criadas com dados de exemplo


PASSO 2 - Verificar Configuração (1 min)
────────────────────────────────────────
1. Abra arquivo: config/config.php
2. Verifique:
   - DB_HOST = localhost ✓
   - DB_USER = root ✓
   - DB_PASS = (vazio) ✓
   - DB_NAME = trabalho ✓

✅ Se tudo está certo, continuar...


PASSO 3 - Testar a API (1 min)
──────────────────────────────
1. Abra navegador
2. Digite: http://localhost/eng_prog3_2026_1/APISlim/public/api/healthhttp://localhost/eng_prog3_2026_1/APISlim/public/index.php/api/health
3. Você deve ver resposta em JSON com status "online"

✅ Se viu isso, a API está 100% funcional!

❓ SE VOCÊ NÃO CONSEGUIR COMEÇAR:

Problema 1: "Não vejo nada no /api/health"
Solução:
  1. Verifique se .htaccess existe em public/
  2. Verifique se URL está exatamente: 
     http://localhost/eng_prog3_2026_1/APISlim/public/api/health
  3. Limpe cache do navegador (Ctrl+Shift+Del)

Problema 2: "Erro ao conectar ao banco de dados"
Solução:
  1. Verifique se MySQL está rodando (Laragon)
  2. Verifique se executou setup.sql
  3. Verifique config.php tem credenciais corretas

Problema 3: "Não sei por onde começar"
Solução:
  1. Leia QUICK_START.md (5 minutos)
  2. Siga os 3 passos descritos aqui
  3. Sucesso! 🎉
