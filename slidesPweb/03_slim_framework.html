Por que usar um Framework?

Sem framework (PHP puro):

  • Roteamento manual com $_SERVER['REQUEST_URI']
  • Headers CORS repetidos em cada arquivo
  • Sem organização padronizada de código
  • Difícil de escalar e manter
  • Código duplicado em vários lugares

Funciona para projetos pequenos, mas vira um caos rapidamente.

Com Slim Framework:

  • Roteamento elegante e declarativo
  • Middleware para CORS, autenticação, logs
  • PSR-7 — objetos Request e Response padronizados
  • Estrutura MVC organizada
  • Testável e extensível

Slim é um micro-framework — fornece o essencial sem impor muita estrutura. Ideal para APIs!

Composer — Gerenciador de Dependências

O Composer é para PHP o que o npm é para Node.js. Gerencia bibliotecas e o autoloading de classes.

Instalar o Slim (terminal)
# Criar projeto
composer init

# Instalar Slim 4 e PSR-7
composer require slim/slim
composer require slim/psr7

# Ou criar um projeto direto:
composer create-project slim/slim-skeleton meu-projeto
composer.json — autoload PSR-4
{
  "autoload": {
    "psr-4": {
      "App\\": "src/"
    }
  },
  "require": {
    "slim/slim": "^4.0",
    "slim/psr7": "^1.0"
  }
}

Após instalar, execute:

# Gera o autoloader
composer dump-autoload

public/index.php — O Coração da API

public/index.php
<?php
use Slim\Factory\AppFactory;
use App\Controllers\ServicoController;
use App\Middlewares\CorsMiddleware;

require dirname(__DIR__) . '/vendor/autoload.php';
require dirname(__DIR__) . '/config/config.php';

// 1. Criar a aplicação Slim
$app = AppFactory::create();

// 2. Definir base path (para Laragon)
$app->setBasePath('/eng_prog3_2026_1/APISlim/public');

// 3. Adicionar Middlewares
$app->addBodyParsingMiddleware();   // parseia JSON do body
$app->addRoutingMiddleware();
$app->add(new CorsMiddleware());

// 4. Definir rotas
$app->get('/api/health', function($req, $res) {
    return $res->withJson(['status' => 'online']);
});

$app->get('/api/servicos',    [ServicoController::class, 'index']);
$app->get('/api/servicos/{id}', [ServicoController::class, 'show']);
$app->post('/api/servicos',   [ServicoController::class, 'store']);
$app->put('/api/servicos/{id}', [ServicoController::class, 'update']);
$app->delete('/api/servicos/{id}', [ServicoController::class, 'destroy']);

// 5. Executar
$app->run();

PSR-7 — Request & Response

O PSR-7 é um padrão que define interfaces imutáveis para mensagens HTTP. Todo controller recebe e retorna objetos PSR-7.

Objeto Request
// Assinatura de todo handler
function(Request $request, Response $response, array $args): Response

// Lendo dados do Request
$request->getMethod();           // "GET", "POST"...
$request->getUri()->getPath();   // "/api/servicos"
$request->getParsedBody();        // array do JSON body
$request->getQueryParams();       // array da query string
$request->getHeaderLine('Accept'); // valor do header
Objeto Response
// Response é IMUTÁVEL — cada método retorna NOVO objeto!

// Escrever JSON manualmente
$payload = json_encode(['ok' => true]);
$response->getBody()->write($payload);
return $response->withHeader(
    'Content-Type', 'application/json'
)->withStatus(200);

// Definir código de status
return $response->withStatus(404);
return $response->withStatus(201);

// Adicionar header
return $response->withHeader('X-Custom', 'valor');

O nosso Response.php (utilitário) encapsula a lógica de resposta JSON para não repetir esse código em todos os controllers.

Middlewares

src/Middlewares/CorsMiddleware.php
<?php
namespace App\Middlewares;

use Psr\Http\Message\ServerRequestInterface as Request;
use Psr\Http\Server\RequestHandlerInterface as Handler;

class CorsMiddleware {
    public function __invoke(Request $request, Handler $handler) {
        // Trata OPTIONS (preflight do browser)
        if ($request->getMethod() === 'OPTIONS') {
            $response = new \Slim\Psr7\Response();
        } else {
            $response = $handler->handle($request); // executa o handler
        }

        // Adiciona headers CORS à resposta
        return $response
            ->withHeader('Access-Control-Allow-Origin', '*')
            ->withHeader('Access-Control-Allow-Methods', 'GET,POST,PUT,DELETE,OPTIONS')
            ->withHeader('Access-Control-Allow-Headers', 'Content-Type,Authorization');
    }
}

ServicoController — Camada de Controle

src/Controllers/ServicoController.php
<?php
namespace App\Controllers;

use App\Models\Servico;
use App\Utils\Response;
use Psr\Http\Message\ServerRequestInterface as Req;
use Psr\Http\Message\ResponseInterface as Res;

class ServicoController {

    /** GET /api/servicos */
    public function index(Req $req, Res $res): Res {
        $servicos = (new Servico())->getAll();
        return Response::json($res, $servicos);
    }

    /** GET /api/servicos/{id} */
    public function show(Req $req, Res $res, array $args): Res {
        $servico = (new Servico())->find((int) $args['id']);
        if (!$servico) {
            return Response::error($res, 'Não encontrado', 404);
        }
        return Response::json($res, $servico);
    }

    /** POST /api/servicos */
    public function store(Req $req, Res $res): Res {
        $data = (array) $req->getParsedBody();
        if (empty($data['titulo'])) {
            return Response::error($res, 'Título obrigatório', 400);
        }
        $id = (new Servico())->create($data);
        return Response::json($res, ['id' => $id], 201);
    }
}

O controller deve ser "magro":

  • Recebe a requisição
  • Valida os dados de entrada
  • Chama o Model
  • Retorna a resposta

Não deve:

  • Conter queries SQL diretamente
  • Fazer lógica de negócio complexa
  • Acessar banco sem usar o Model

Separação de responsabilidades torna o código testável e fácil de manter.

Os métodos index, show, store, update, destroy seguem a convenção REST dos frameworks.

Servico Model — Camada de Dados

src/Models/Servico.php
<?php
namespace App\Models;

class Servico {
    private $db;

    public function __construct() {
        $this->db = Database::getInstance()->getConnection();
    }

    public function getAll(): array {
        $stmt = $this->db->query("SELECT * FROM servicos ORDER BY id DESC");
        return $stmt->fetchAll();
    }

    public function find(int $id): ?array {
        $stmt = $this->db->prepare("SELECT * FROM servicos WHERE id = :id");
        $stmt->execute([':id' => $id]);
        $row = $stmt->fetch();
        return $row ?: null;
    }

    public function create(array $data): int {
        $sql = "INSERT INTO servicos (titulo, descricao, preco)
                VALUES (:titulo, :descricao, :preco)";
        $stmt = $this->db->prepare($sql);
        $stmt->execute([
            ':titulo'    => trim($data['titulo']),
            ':descricao' => $data['descricao'] ?? '',
            ':preco'     => (float) ($data['preco'] ?? 0),
        ]);
        return (int) $this->db->lastInsertId();
    }
}
src/Models/Database.php — Singleton
<?php
namespace App\Models;

class Database {
    private static ?Database $instance = null;
    private PDO $connection;

    private function __construct() {
        $config = require dirname(__DIR__, 2) . '/config/config.php';
        $dsn = "mysql:host={$config['db']['host']};dbname={$config['db']['name']};charset=utf8";
        $this->connection = new PDO($dsn,
            $config['db']['user'],
            $config['db']['pass'],
            [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
             PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC]
        );
    }

    public static function getInstance(): self {
        if (self::$instance === null) {
            self::$instance = new self();
        }
        return self::$instance;
    }

    public function getConnection(): PDO {
        return $this->connection;
    }
}

Utils/Response.php — Respostas Padronizadas

src/Utils/Response.php
<?php
namespace App\Utils;

use Psr\Http\Message\ResponseInterface;

class Response {

    /** Resposta de sucesso */
    public static function json(
        ResponseInterface $res,
        $data,
        int $status = 200
    ): ResponseInterface {
        $payload = json_encode([
            'success' => true,
            'data'    => $data,
        ], JSON_UNESCAPED_UNICODE);
        $res->getBody()->write($payload);
        return $res
            ->withHeader('Content-Type', 'application/json')
            ->withStatus($status);
    }

    /** Resposta de erro */
    public static function error(
        ResponseInterface $res,
        string $message,
        int $status = 400
    ): ResponseInterface {
        $payload = json_encode([
            'success' => false,
            'error'   => $message,
        ], JSON_UNESCAPED_UNICODE);
        $res->getBody()->write($payload);
        return $res
            ->withHeader('Content-Type', 'application/json')
            ->withStatus($status);
    }
}

CRUD Completo — Fluxo de uma Requisição

Exemplo: PUT /api/servicos/3 — atualizar serviço

Controller — update()
public function update(Req $req, Res $res, array $args): Res {
    $id   = (int) $args['id'];
    $data = (array) $req->getParsedBody();
    $model = new Servico();

    // 1. Verificar se existe
    if (!$model->find($id)) {
        return Response::error($res, 'Não encontrado', 404);
    }
    // 2. Validar
    if (empty($data['titulo'])) {
        return Response::error($res, 'Título obrigatório', 400);
    }
    // 3. Atualizar
    $model->update($id, $data);

    // 4. Retornar registro atualizado
    return Response::json($res, $model->find($id));
}
Model — update() e destroy()
public function update(int $id, array $data): bool {
    $sql = "UPDATE servicos
             SET titulo = :titulo,
                 descricao = :descricao,
                 preco = :preco
             WHERE id = :id";
    $stmt = $this->db->prepare($sql);
    return $stmt->execute([
        ':titulo'    => trim($data['titulo']),
        ':descricao' => $data['descricao'] ?? '',
        ':preco'     => (float) ($data['preco'] ?? 0),
        ':id'        => $id,
    ]);
}

public function destroy(int $id): bool {
    $stmt = $this->db->prepare(
        "DELETE FROM servicos WHERE id = :id"
    );
    return $stmt->execute([':id' => $id]);
}

.htaccess — Roteamento no Apache

Para que o Slim receba todas as requisições e faça o roteamento, o Apache precisa redirecionar tudo para o index.php:

public/.htaccess
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^ index.php [QSA,L]

O que isso faz:

  1. Ativa o módulo de rewrite do Apache
  2. Se a URL não é um arquivo real (!-f)
  3. E não é uma pasta real (!-d)
  4. Redireciona para index.php

Sem o .htaccess, URLs como /api/servicos retornariam 404 do Apache. O Slim nunca seria chamado.

Verifique se o módulo mod_rewrite está ativo no Apache do Laragon: Laragon → Apache → httpd.conf

Erros Comuns e Soluções

Erro Causa Solução
404 Not Found Base path incorreto Verificar $app->setBasePath() e .htaccess
CORS Error Headers CORS ausentes Adicionar CorsMiddleware e tratar OPTIONS
500 Error Erro PHP/BD Ver log Apache: C:\laragon\logs\apache\
Body vazio Faltou addBodyParsingMiddleware Adicionar antes das rotas no index.php
Autoload falha Namespace errado Verificar composer.json e executar composer dump-autoload
JSON inválido BOM ou espaço antes de <?php Remover espaços/linhas antes da tag PHP

Dica de debug: Adicione error_reporting(E_ALL); e ini_set('display_errors', 1); no início do index.php durante o desenvolvimento.

Padrão Genérico — Generic Actions + AbstractRepository

A partir do projeto real prog3_API_teste, criamos um padrão reutilizável que reduz 50% do código:

Problema Original:

  • Cada CRUD (Cliente, Serviço, Prestador) = 430 linhas
  • Muita duplicação de código (método findAll, create, update, delete)
  • Mudança em lógica = editar 6+ arquivos
  • Novo CRUD = 2 horas de trabalho

Solução Implementada:

  • AbstractRepository (170 linhas) — base CRUD genérica
  • 6 GenericActions — List, View, Create, Update, Delete, Search
  • Herança simples — cada novo CRUD = 70 linhas
  • Novo CRUD = 15 minutos ⚡

Aspecto PHP Puro Slim Framework
